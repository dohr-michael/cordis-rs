# cordis-loader

Immutable declarative loading plans and synchronous typed target resolution for Cordis v3. This `0.1.x` line is a replacement architecture, not a source-compatible continuation of the legacy `0.0.x` loader.

```toml
[dependencies]
cordis-rs = "0.7"
cordis-loader = "0.1"
```

See `MIGRATION.md` and `docs/v3-migration.md` for the v3 transition.
